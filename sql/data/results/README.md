# Water Quality SQL Analysis

## Project Overview

This project demonstrates SQL skills by analyzing environmental water quality data. The goal is to practice querying environmental datasets using SQL to answer common questions related to environmental monitoring.

## Skills Demonstrated

- SQL
- Data filtering
- Data aggregation
- Environmental data analysis
- Environmental monitoring

## Project Objectives

- Explore environmental water quality data
- Write SQL queries to retrieve information
- Summarize monitoring results
- Practice SQL for environmental science applications
